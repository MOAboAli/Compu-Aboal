# Admin Guide

## Login
- URL: `/admin`
- Default seed account: `admin@compu-aboali.com` / `Admin123!`

## Capabilities
- Manage users and roles
- Manage categories and products
- Process orders and shipment statuses
- Manage service offerings and service requests
- Edit CMS home content
- View sales/service/user reports and simulated exports
- Search audit logs
- Run/restore simulated backups

## Notes
- Direct pushes to `develop` and `main` are blocked; use feature branches and PRs.
- Payment/SMS/email actions are simulated for development.
