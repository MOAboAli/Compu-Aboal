# User Guide

## Website
- Browse featured products/services on Home
- Shop with search and category filters
- Add items to cart/wishlist (login required)
- Checkout opens a simulated payment page (InstaPay/Visa/MasterCard/Fawry)
- Request site survey or maintenance under Services
- Track orders and service requests in Account

## Languages
Use the EN / عربي toggle in the header (RTL supported for Arabic).
